# Charte graphique — thème doré

Style : **banque privée, pas casino**. Sobre, haut de gamme, beaucoup d'espace. Aucun visuel de billets, voitures de luxe ou gains.

## Couleurs
| Rôle | Valeur |
|---|---|
| Fond noir profond | `#0B0B0C` |
| Surfaces | `#141416` |
| Or principal | `#C9A227` |
| Or clair | `#E6C766` |
| Texte blanc cassé | `#F5F1E6` |
| Texte secondaire | `#A8A29A` |

## Détails
- Dégradé or discret sur boutons principaux et titres clés ; filets dorés fins.
- Titres : serif élégante (Playfair Display ou Cormorant Garamond). Texte : Inter.
- Graphiques en or et gris, lisibles. Contrastes WCAG AA. Parfait sur mobile.
